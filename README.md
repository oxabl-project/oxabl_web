# oxabl-web

Marketing site for [Oxabl](https://github.com/oxabl-project/oxabl) — high-performance tooling for Progress ABL, written in Rust.

Part of the [`<kbd>` tag](https://github.com/evanbrobertson) brand family.

## Stack

- [Astro](https://astro.build) 6
- React islands (HoverGlow)
- Tailwind CSS 4 + shadcn/ui (base-luma)
- Geist / IBM Plex Sans / JetBrains Mono

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```

## Updating the Oxabl WebAssembly package

The browser package is generated by the Oxabl repository and checked into
`src/wasm` so Railway's build remains deterministic and does not depend on
another repository's moving `master` branch.

From an Oxabl checkout with the matching `wasm-bindgen` CLI installed:

```bash
./scripts/build-wasm.sh /path/to/oxabl_web/src/wasm
```

The UI is deliberately a thin client. It calls the shared Oxabl single-file
analysis and safe formatter pipelines; project includes, schema-backed checks,
and workspace config are not reimplemented in the website.

The generated JavaScript and `.wasm` file must stay together under `src/wasm`.
Vite processes the glue module and rewrites its relative WebAssembly URL for
both development and production builds.

## Brand notes

- Logo wordmark is `ox_abl` — green underscore is intentional
- Palette is kbd-tag neutrals + an ABL-adjacent green accent (not Progress brand colors)
- Keyboard shortcuts (`h` / `f` / `p` / `s`) match the kbd-tag nav language
- Footer states the project is unofficial and unaffiliated
