# Martian Mono chrome subset

`martian-mono-chrome.woff2` is derived from Martian Mono v6 as packaged by
`@fontsource-variable/martian-mono@5.3.0`. It contains only ASCII uppercase,
digits, space, and punctuation (`U+0020–0040`, `U+0041–005A`, `U+005B–0060`,
`U+007B–007E`). HarfBuzz performed the glyph subset and WOFF2 encoded the
result. Martian Mono is distributed under the SIL Open Font License 1.1; the
source package carries the license and upstream attribution.
